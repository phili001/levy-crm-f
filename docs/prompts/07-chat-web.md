Prepara el chat de Sofía para la página web de la clínica (dominio del CRM: <dominio>).

1. Pregúntame la dirección de la web donde va a ir el chat (https://…).
2. Corre `python3 scripts/omni.py connect widget --instance <dominio> --dominios <dirección de la web>`. Sin `--dominios`, cualquier web podría usar a Sofía a mi costa: si no tengo la dirección clara, dímelo antes de seguir.
3. Dime dónde copio el código para pegar (en el panel: Canales → Servicios → Chat en tu web) y cómo se pega en mi plataforma (WordPress, Wix, HTML…).
4. Cuando esté pegado, abro la web y escribo algo en el chat para comprobarlo.
